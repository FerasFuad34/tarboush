 طَربوش 🎓 — ذاكر محاضرتك بذكاء
 المرحلة الأولى M1 — نسخة جاهزة للتشغيل
============================================================

المتطلبات (مرة واحدة فقط):
  1. Docker Desktop for Windows  →  https://www.docker.com/products/docker-desktop
  2. (اختياري لكنه يرفع الجودة كثيراً) Ollama  →  https://ollama.com
     بعد تثبيته افتح PowerShell واكتب:
        ollama pull qwen2.5:7b

خطوات التشغيل:
  1) فك ضغط هذا الملف في مجلد مثل:  C:\tarboush
  2) افتح PowerShell داخل المجلد واكتب:
        cd C:\tarboush
        copy .env.example .env
        docker-compose up --build
  3) انتظر حتى تظهر رسالة أن الخدمات جاهزة، ثم افتح المتصفح على:
        http://localhost:3000      ← الواجهة العربية
        http://localhost:8000/docs ← توثيق الـ API
        http://localhost:5555      ← مراقبة الطابور (Flower)

أول تجربة (ملفات جاهزة داخل docs\samples):
  • lecture_physics_ar.txt      ← محاضرة نصية عربية (الأسرع، ثوانٍ)
  • lecture_physics_ar_45s.mp3  ← تسجيل صوتي عربي 45 ثانية لاختبار التفريغ والمشغل

  ارفع أحدها من زر «رفع محاضرة» → راقب النسبة المئوية → افتح المحاضرة بعد «مكتملة».

لماذا Docker؟
  لأنه يجهّز ffmpeg + Tesseract العربي + كل مكتبات بايثون تلقائياً،
  فلا تحتاج تثبيت أي شيء يدوياً على ويندوز.

بدون Docker (تطوير فقط):
  cd backend
  pip install -r requirements.txt
  uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
  ثم في نافذة ثانية:
  cd frontend && npm install && npm run dev
