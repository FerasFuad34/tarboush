طربوش — ابدأ من هنا  (الإصدار 1.4)
==========================================

⚡ أسرع طريقة (محلياً، بلا Docker وبلا إنترنت بعد التثبيت الأول)
-----------------------------------------------------------------
  ويندوز:
      انقر نقراً مزدوجاً على:  start-windows.bat
      (أول مرة: يثبّت كل شيء تلقائياً — قد تأخذ 5–10 دقائق)
      ثم يفتح المتصفح على:  http://127.0.0.1:8000

  لينكس / ماك:
      ./start-local.sh
      ثم افتح:  http://127.0.0.1:8000

  الواجهة والـ API على منفذ واحد — لا حاجة لتشغيل خدمتين.


📦 ما الذي صار يقبله طربوش الآن؟
--------------------------------
  • أي صيغة صوت وفيديو: MP3, WAV, M4A, MP4, MKV, AVI, MOV, WEBM, FLV,
    WMV, TS, 3GP, OGG, FLAC… النوع يُقرأ من محتوى الملف لا من اسمه.
  • أي مستند: PDF (نصي أو ممسوح بـ OCR), DOCX, DOC, PPTX, PPT, XLSX, XLS,
    ODT, ODP, ODS, RTF, EPUB, TXT, MD, SRT/VTT، وأي ملف نصي أو كود.
  • صور: PNG, JPG, TIFF, BMP, WEBP, GIF  → تُقرأ بـ OCR (عربي + إنجليزي).
  • أرشيف: ZIP وما بداخله (حتى عمقين).
  • ملف بامتداد مجهول: يُفحص ويُقبل إن كان نصاً أو وسائط.

  • بلا سقف حجم (الحد الوحيد مساحة قرصك) — مع رفع مجزّأ يُستأنف تلقائياً.
  • تسجيل مباشر من الميكروفون بلا حد للمدة (ساعة كاملة تعمل).
  • محاضرة 32 دقيقة فيديو: مجرَّبة فعلياً — تفريغ كامل بطوابع متصلة.
  • لا يوجد أي تخصص أو مادة مبرمجة في الكود: أي موضوع، أي كلية.
  • اللغة تُكتشف تلقائياً (عربي، إنجليزي، غيرها).


🧰 المتطلبات (مرة واحدة)
--------------------------
  1) Python 3.10+        → python.org  (علّم على "Add Python to PATH")
  2) ffmpeg              → winget install ffmpeg
     (بدونه: المستندات تعمل، لكن الصوت والفيديو لا)
  3) Tesseract (اختياري)  → للصور و PDF الممسوح
       ويندوز: نزّل tesseract مع حزمة اللغة العربية
       لينكس:  sudo apt install tesseract-ocr tesseract-ocr-ara

  تحقّق من الجاهزية في أي وقت:  افتح  http://127.0.0.1:8000/health


⏱️ كم يستغرق التفريغ؟
----------------------
  يعتمد على نموذج Whisper في backend/.env  (STT_MODEL):
     tiny   = الأسرع، دقة أقل        (~0.1× مدة المحاضرة على CPU حديث)
     small  = توازن جيد              (~0.25×)
     medium = الافتراضي، أدق         (~0.4–0.6×)

  مثال: محاضرة 30 دقيقة بنموذج medium ≈ 12–18 دقيقة معالجة، مرة واحدة فقط،
  وبعدها النص والملخصات والأسئلة محفوظة.


📄 النتائج التي تحصل عليها لكل محاضرة
--------------------------------------
  نص كامل قابل للبحث + طوابع زمنية + مشغل (صوت أو فيديو)
  + 3 مستويات تلخيص + أهم 10 أفكار
  + قاموس مصطلحات (عربي/إنجليزي) + 10 أسئلة مراجعة بتصحيح ودرجة
  + تقسيم تلقائي إلى مواضيع + مصادر شرح حقيقية لكل موضوع
  + تصدير PDF / DOCX / MD / JSON / TXT


🗂️ أين تُحفظ ملفاتي؟
---------------------
  backend/storage/uploads   ← الملفات المرفوعة
  backend/storage/exports   ← ملفات التصدير
  backend/storage/tarboush.db ← قاعدة البيانات (SQLite)


🆘 إن لم يعمل شيء
------------------
  1) افتح  http://127.0.0.1:8000/health  واقرأ ما هو غير جاهز.
  2) تأكد أن ffmpeg يعمل:  افتح CMD واكتب  ffmpeg -version
  3) إن كان المنفذ 8000 مشغولاً: عدّل آخر سطر في start-windows.bat
     من --port 8000 إلى --port 8080 ثم افتح http://127.0.0.1:8080
  4) سجلّ الخادم يظهر في نفس النافذة السوداء — لا تغلقها أثناء العمل.
