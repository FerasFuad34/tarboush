# الشرح والمصادر — ربط كل محاضرة بمصادر خارجية حقيقية

> هذه الميزة **مبنية وتعمل فعلياً**، وكل رقم في هذا الملف مأخوذ من تشغيل حقيقي
> على الخادم المحلي في هذه البيئة (لا تقديرات ولا بيانات تجريبية).

---

## ما الذي تفعله؟

بعد انتهاء خط المعالجة (تفريغ → تلخيص → قاموس → أسئلة) يضيف طربوش مرحلتين جديدتين:

1. **تقسيم المحاضرة إلى مواضيع** (`app/services/topics.py`)
   — لكل موضوع: عنوان من كلام المحاضرة نفسه، مقتطف حرفي، مصطلحات، ووقت البداية/النهاية.
2. **البحث عن شرح خارجي لكل موضوع** (`app/services/resources.py`)
   — يوتيوب + ويكيبيديا + ويكي الجامعة + ويكي الكتب + arXiv، عبر واجهات **مجانية بلا مفاتيح**.

ثم تُعرض المصادر **داخل مسار الشرح** في تبويب «الشرح والمصادر» (وهو التبويب الافتراضي
عند فتح المحاضرة)، وتُضمَّن أيضاً في كل صيغ التصدير (PDF/DOCX/Markdown/JSON/TXT).

### قاعدتان صارمتان التُزمتا

| القاعدة (من طلبك) | كيف نُفِّذت |
| :--- | :--- |
| **لا مادة ولا مقرر محدد مسبقاً** | لا توجد أي قائمة مواد/كلمات مفتاحية في الكود. المواضيع تُستخرج من نص المحاضرة، والاستعلامات تُبنى من عنوان الموضوع نفسه فقط. جرّبناه على الفيزياء والاقتصاد دون أي تغيير في الكود. |
| **الحجم حسب كل محاضرة** | عدد المواضيع = `max(3, min(8, الكلمات ÷ 220))`، وعدد المصادر يتبع عدد المواضيع والمزودين، و`MAX_UPLOAD_SIZE_MB=0` يعني لا سقف حجم. |
| **أداة حقيقية لا وهم** | كل رابط في قاعدة البيانات هو نتيجة بحث حقيقي (مُتحقَّق منه: يوتيوب عبر `yt-dlp`، والويكي عبر MediaWiki API). لا يوجد أي رابط مُصطنع أو مكتوب يدوياً في الكود. |

## كيف يعمل التقسيم إلى مواضيع؟

```
نص المحاضرة → جُمَل → تقسيم إلى مقاطع متساوية (حسب عدد الكلمات)
            → TF-IDF عبر المقاطع (كلمة تظهر في كل مقطع تفقد وزنها)
            → اختيار أفضل عبارة *حرفية* من جمل المقطع (كلمتان متجاورتان)
            → استبعاد العناوين المتشابهة (تشابه ≥ 50% = موضوع مكرر)
```

نقاط دقيقة أُصلحت أثناء التطوير (موثّقة لأنها أخطاء حقيقية وقعت):

- **لا نُركّب «و» بين كلمتين**: التركيب يحوّل «الكمية المطلوبة» إلى «الكمية والمطلوبة»،
  و«الكتلة والوزن» إلى «الكتلة ووزن». الآن نأخذ العبارة **كما وردت** في المحاضرة.
- **البادئات واللواصق**: «بالكيلوجرام → كيلوجرام»، «ووحدة → وحدة»، مع حفظ «والوزن»
  داخل العبارة (لأنها جزء من العبارة الأصلية).
- **كلمات عامة لا تصلح عنواناً**: «وحدة، معنى، مفهوم، درس...» تُستبعد من حساب الصلة.

## كيف يُختار المصدر؟ (فلترة الصلة)

لكل موضوع يُبنى استعلامان:

| المزود | الاستعلام | لماذا |
| :--- | :--- | :--- |
| يوتيوب | `عنوان الموضوع + شرح` | يوتيوب يفهم اللغة الطبيعية |
| ويكيبيديا/ويكي الجامعة/ويكي الكتب | `عنوان الموضوع` فقط | الويكي تفضّل اسم المفهوم مجرداً |
| arXiv | المصطلحات الإنجليزية فقط | arXiv لا يجيب العربية |

ثم **فلترة صلة** قبل التخزين: تُقارن كلمات عنوان الموضوع مع عنوان النتيجة باستخدام
«هيكل» عربي (حذف حروف المد) حتى يتساوى «قانون» مع «قوانين»، ويُشترط تطابق كلمتين
(أو كلمة واحدة إذا كان العنوان كلمة واحدة). النتيجة: «صاروخ» و«غال (وحدة)» لا تظهران
في موضوع عن التسارع، و«مصدران صحيحان» أفضل من «خمسة بينها ما لا علاقة له».

كما نمنع تكرار نفس الرابط بين موضوعين (يُعطى للموضوع الأول، ويُعاد للموضوع الأخير إن
كان سيصبح بلا مصادر).

## المزوّدون (مصفوفة حقيقية)

| المزود | الحالة | ملاحظة صدق |
| :--- | :---: | :--- |
| يوتيوب (`yt-dlp ytsearch`) | ✅ | يعيد عنواناً + قناة + مدة + مصغّرة `i.ytimg.com`. فلتر مدة 90 ثانية – ساعتان. |
| ويكيبيديا العربية (MediaWiki API) | ✅ | عنوان + مقتطف. |
| ويكي الجامعة العربية | ✅ | غالباً دروس، لكن التغطية أضعف من ويكيبيديا. |
| ويكي الكتب العربية | ✅ | تغطية محدودة؛ قد يعود Topic بلا مصادر منه. |
| arXiv | ✅ | **إنجليزي فقط** — لا يعيد شيئاً للمواضيع العربية بلا مصطلح إنجليزي. |
| DuckDuckGo HTML | ❌ مُلغى | يعيد HTTP 202 بلا نتائج من هذه البيئة — لا تُعِد المحاولة. |

**قيود حقيقية يجب معرفتها:**

- ويكيميديا تحدّ الطلبات (HTTP 429) عند إرسال طلبات كثيرة متزامنة. عالجناها بـ:
  طلب واحد كل 0.6 ثانية، إعادة محاولة 4 مرات بتباعد أسّي، كاش داخلي 6 ساعات،
  وعدم سؤال ويكي الجامعة/الكتب إلا إذا لم تُغطِّ ويكيبيديا الموضوع (يقلل الطلبات للثلث).
- تضمين فيديو يوتيوب داخل الصفحة (`iframe`) قد يظهر برسالة «تأكّد أنك لست روبوتاً»
  إذا كان الاتصال من عنوان IP لمركز بيانات (كما في بيئة الاختبار). هذا سلوك يوتيوب نفسه،
  وليس خطأً في طربوش؛ على جهاز المستخدم يعمل الفيديو. لذلك رابط «فتح المصدر» موجود دائماً.
- مصغّرات يوتيوب تُحمّل من `i.ytimg.com`؛ إن كانت الشبكة تحجبها يظهر بديل ملوّن بالحرف
  الأول للمزود بدل صورة مكسورة.

## واجهات API الجديدة

### `GET /api/v1/lectures/{id}`
أصبح يُرجع `topics` مباشرة مع كل موضوع:

```json
{
  "topics": [
    {
      "id": 1, "order": 0,
      "title": "قانون نيوتن",
      "excerpt": "محاضرة فيزياء - الفصل الأول: قوانين نيوتن بسم الله...",
      "key_terms": ["قوانين", "نيوتن", "الفصل"],
      "start_seconds": 0, "end_seconds": 90,
      "resources": [
        {
          "id": 1, "provider": "youtube",
          "title": "ما هو قانون نيوتن الثاني؟ وما أهميته؟",
          "url": "https://www.youtube.com/watch?v=ceTqCEAVQEE",
          "thumbnail": "https://i.ytimg.com/vi/ceTqCEAVQEE/mqdefault.jpg",
          "duration_seconds": 733, "channel": "المصباح العلمي", "lang": "ar"
        }
      ]
    }
  ]
}
```

### `POST /api/v1/lectures/{id}/topics/relink`
زر «↻ تحديث المصادر» في الواجهة: يمسح مصادر المواضيع ويعيد البحث من جديد
(المواضيع نفسها تبقى كما هي — لا يُعاد التفريغ ولا التلخيص).

### `GET /api/v1/lectures/resources/search?q=...&limit=8`
بحث حر عن أي مفهوم (مربّع «ابحث عن شرح لأي مفهوم بنفسك» أسفل التبويب).
عند عدم وجود نتائج يعيد `count: 0` مع `note: "لا توجد نتائج مطابقة"` — **بلا اختلاق**.

## الإعدادات

```env
RESOURCES_ENABLED=true
RESOURCE_PROVIDERS=youtube,wikipedia,wikiversity,wikibooks,arxiv
YOUTUBE_RESULTS_PER_TOPIC=3
WIKI_RESULTS_PER_TOPIC=2
RESOURCE_SEARCH_TIMEOUT=15
MAX_UPLOAD_SIZE_MB=0     # 0 = بلا سقف
```

تعطيل الميزة بالكامل (`RESOURCES_ENABLED=false`) لا يُعطّل المنصة: تُستخرج المواضيع
ويظهر مكان المصادر تنبيه صادق «لم نجد مصدراً مطابقاً لهذا الموضوع».

## نتائج الاختبار الحقيقية

### الدورة الكاملة (محاضرة فيزياء 196 كلمة، نصّية)

```
[Pipeline 1] topics - 85%
[Pipeline 1] resources - 90%
[Pipeline] مصادر مرتبطة: 12 عبر 3 موضوع
[Pipeline 1] done - 100%
```

| الموضوع | المصادر |
| :--- | :--- |
| قانون نيوتن | 5 (3 يوتيوب + 2 ويكيبيديا) |
| الكتلة والوزن | 4 (3 يوتيوب + 1 ويكيبيديا) |
| وحدة التسارع | 3 (3 يوتيوب) |

### محاضرة مادة أخرى (اقتصاد جزئي، 330 كلمة) — إثبات عدم التشفير

| الموضوع | أمثلة على المصادر الحقيقية |
| :--- | :--- |
| الكمية المعروضة | «التغير في الكمية المعروضة والتغير في العرض» (يوتيوب) |
| النسبة المئوية | «الرياضيات \| النسبة المئوية \| أ. حسن محمد النزهي» (يوتيوب) |
| منحنى الطلب | «منحنى الطلب ومنحنى العرض ببساطة» (يوتيوب) + «منحنى الطلب» (ويكيبيديا) |

لم يُعدَّل سطر واحد في الكود بين المحاضرتين — نفس الخدمة أنتجت مواضيع مختلفة تماماً.

### فحوص E2E (`python tests/e2e_check.py http://localhost:8000`)

```

✅ عناوين المواضيع غير مكررة
✅ مصادر خارجية مرتبطة — 12 مصدر
✅ كل الروابط من مزودين معروفين — 2 مزود
✅ لا تكرار في المصادر — 12 رابط فريد / 12
✅ لكل موضوع مصدر واحد على الأقل — [5, 4, 3]
✅ زر تحديث المصادر يعمل بلا تكرار — قبل 12 / بعد 12
✅ بحث حر يعيد نتائج حقيقية — 5 نتيجة
✅ حالة صادقة عند عدم وجود نتائج — لا توجد نتائج مطابقة
✅ المصادر داخل تصدير Markdown
✅ المصادر داخل تصدير JSON
...
نجح 27 من 27
```

> ملاحظة صدق: في هذه الحاوية لا يوجد `faster-whisper` ولا `ffmpeg` ولا Redis/Ollama،
> لذلك تُخطَّى فحوص الصوت وثلاثة ملفات مستندات غير موجودة في البيئة، ويظهر ذلك
> بسطر `⏭️ تخطّي` صريح. الرقم أعلاه هو 27 من 27 للفحوص التي أمكن تشغيلها.

### الواجهة (Playwright على متصفح حقيقي)

- تبويب «الشرح والمصادر» يظهر أولاً ومحدداً افتراضياً.
- الضغط على «شاهد هنا» يفتح مشغّل يوتيوب مضمّناً داخل بطاقة المصدر.
- البحث اليدوي «الاحتباس الحراري» أعاد 4 نتائج حقيقية (2 يوتيوب + 2 ويكيبيديا).
- لا أخطاء JavaScript في الـ console.

  `12_free_search.png`، `13_topics_econ.png`، `14_topics_mobile.png`، `16_pdf_sources.png`.

## ما لم يُنفَّذ بعد (بصراحة)

- ⬜ **شرح مولَّد بالذكاء الاصطناعي لكل موضوع** (فقرة شرح مكتوبة، لا مجرد روابط):
  يحتاج LLM محلي يعمل؛ في هذه البيئة Ollama غير متاح. الروابط والمقتطفات تعمل الآن.
- ⬜ **ترتيب المصادر بجودة الشرح** (مشاهدات/تقييم): `yt-dlp` لا يعطي إحصاءات في وضع البحث.
- 🟡 **ويكيميديا تحت الحجب المؤقت (429)**: نتجاوزه بإعادة المحاولة والكاش، لكن التغطية
  قد تقلّ في الدقائق المزدحمة.
- ⬜ **بحث عربي عام (محرك ويب)**: DuckDuckGo محجوب من هذه البيئة؛ البديل المجاني بلا مفاتيح
  يحتاج مفتاح API (وهذا يخالف قاعدة «مجاني الأساس»).
