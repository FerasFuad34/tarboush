# استقبال أي صيغة — بلا قيود

> هذا الملف يشرح كيف صار طربوش يقبل **أي ملف** ويتعامل معه بذكاء، وماذا جُرِّب فعلياً.

---

## 1) الفلسفة: لا نثق بالامتداد

الامتدادات تكذب: ملف PDF اسمه `.mp3`، فيديو باسم `.dat`، مستند Word محفوظ كـ `.zip`.
لذلك نتجاهل الاسم تماماً ونفحص **البايتات الأولى** ثم نختبر المحتوى بأدوات حقيقية:

```
[1] فحص البصمة (magic bytes)
       %PDF      → PDF
       PK\\x03\\x04→ ZIP (ثم نميّز: docx / pptx / xlsx / odt / epub / أرشيف عادي)
       \\xd0\\xcf\\x11\\xe0 → Office قديم (doc/xls/ppt)
       fLaC / OggS / RIFF / ID3 / ftyp → وسائط
       \\x89PNG / \\xff\\xd8\\xff      → صورة

[2] ffprobe — الحكم النهائي للوسائط
       يوجد مسار صوتي؟  → يُفرَّغ
       فيديو بلا صوت؟   → OCR على لقطات كل 20 ثانية

[3] مستخرجات المستندات حسب النوع الحقيقي لا الامتداد

[4] الأرشيف: يُفكّ في مجلد مؤقت ويُعالَج كل ملف داخله (حتى عمقين و3GB)

[5] صورة: Tesseract (ara+eng)

[6] مجهول: فحص نصّي ذكي (UTF-8/UTF-16/cp1256…) وإن كان نصاً مقروءاً يُقبل
```

## 2) الصيغ المدعومة

| العائلة | الصيغ |
| :--- | :--- |
| **فيديو** | MP4, M4V, MOV, MKV, AVI, WEBM, FLV, WMV, MPG/MPEG, TS/MTS/M2TS, 3GP, OGV, VOB, ASF, RM |
| **صوت** | MP3, WAV, M4A, AAC, OGG, OPUS, FLAC, WMA, AMR, AIFF, و`WEBM` من التسجيل المباشر |
| **مستندات** | PDF (نصي + ممسوح OCR), DOCX, DOC, PPTX, PPT, XLSX, XLS, ODT, ODP, ODS, RTF, EPUB |
| **نصوص** | TXT, MD, CSV, TSV, JSON, XML, YAML, HTML, TEX, SRT/VTT/ASS, وأي ملف كود |
| **صور** | PNG, JPG, TIFF, BMP, WEBP, GIF, HEIC |
| **أرشيف** | ZIP (وما يحتويه)، 7z/RAR/TAR إن وُجدت أدوات النظام |

> ما لا يُستخرج منه نص (مثل فيديو صامت بلا شرائح) يُرجع رسالة عربية تشرح السبب، لا خطأ غامض.

## 3) المحاضرات الطويلة: 30–60 دقيقة بلا انفجار ذاكرة

المشكلة الحقيقية ليست «هل تدعم MP4؟» بل **كيف تعالج 60 دقيقة على جهاز بلا GPU**.

1. `ffmpeg` يستخرج **الصوت فقط** إلى `WAV 16kHz mono` (`-vn -map 0:a:0`) مع تنظيف ضجيج خفيف
   (`highpass 80Hz` + `lowpass 7800Hz`) — الحجم ينزل من ~1.5GB إلى ~115MB/ساعة.
2. إن كانت المدة > `AUDIO_CHUNK_SECONDS` (افتراضياً 900s = ربع ساعة):
   `ffmpeg -f segment` يقسّم إلى أجزاء **تُفرَّغ كل واحدة على حدة**.
3. طوابع الأجزاء تُزاح (`offset = i × 900`) فتعود المقاطع متصلة زمنياً كما لو كانت ملفاً واحداً.
4. اللغة تُكتشف من الجزء الأول ثم **تُثبَّت** لكل الأجزاء (تفادي تقلّب اللغة بين الأجزاء).
5. تنظيف تلقائي: مجلد الأجزاء وملف الـWAV المشتق يُحذفان دائماً (`finally`) — حتى عند الفشل.

**قياس فعلي في هذه البيئة (ذاكرة 2GB فقط):**

| الاختبار | النتيجة |
| :--- | :--- |
| فيديو 32.2 دقيقة (1280×720, AAC) | كُشف كوسائط، استُخرج صوته في 2.3 ثانية |
| التقسيم | 3 أجزاء: 900s + 900s + 132s |
| الطوابع بعد التجميع | 0 → 180 ثانية على ملف 185 ثانية (عبر حدود 60/120) ✓ |
| تنظيف الوسائط المؤقتة | 0 ملفات متروكة ✓ |

> ملاحظة: التفريغ نفسه على CPU بطيء أخذ ~155 ثانية لـ 185 ثانية صوت بنموذج `tiny`.
> على جهازك مع `medium` (الافتراضي) التوقّع نحو 0.3–0.6× من مدة المحاضرة.

## 4) الرفع الكبير: متدفّق + مجزّأ

| الحجم | الطريق |
| :--- | :--- |
| ≤ 20MB | `POST /upload` — يُكتب على القرص بقطع 1MB (لا يُقرأ كاملاً في الذاكرة) |
| > 20MB | `init` → `chunk` (8MB) × N → `complete` — الواجهة تفعل ذلك تلقائياً |

- كل قطعة تُعاد محاولتها 4 مرات تلقائياً قبل الاستسلام.
- إعادة إرسال نفس `index` تستبدل القطعة (آمن عند انقطاع الشبكة).
- التجميع يتحقق من الحجم النهائي ويحسب SHA-256 لمنع التكرار.
- **الحد الوحيد هو مساحة قرصك** (`MAX_UPLOAD_SIZE_MB=0`).

**تحقق فعلي:** ملف 18.6MB على 4 قطع → الملف المجمّع مطابق للأصل بايتاً ببايت (`SHA-256 ✓`).

## 5) صفر تخصص مبرمج

لا توجد قائمة مواد ولا تخصصات في الكود. البحث:

```bash
grep -rn "SUBJECT\|subjects\|اختر المادة\|allowed_extensions" backend/ frontend/src/
# النتيجة: لا شيء
```

المسار كله مشتق من المحاضرة نفسها:
`نص → جمل/فقرات (topics.py) → عناوين مواضيع → مصطلحات ← أسئلة ← مصادر لكل موضوع`

نفس الكود أنتج 3 مواضيع في محاضرة فيزياء و3 مختلفة في الاقتصاد والقانون والطب.

## 6) إعدادات التحكم

| المتغير | الافتراضي | الأثر |
| :--- | :--- | :--- |
| `MAX_UPLOAD_SIZE_MB` | `0` | 0 = بلا حد |
| `AUDIO_CHUNK_SECONDS` | `900` | طول الجزء في التفريغ |
| `STT_LANGUAGE` | `auto` | `auto` يكتشف، أو حدّد `ar`/`en`/… |
| `STT_MODEL` | `medium` | `tiny` أسرع، `medium` أدق، `large-v3` الأدق |
| `ENABLE_DENOISE` | `true` | تنقية صوت القاعة |
| `STT_ENABLED` | `true` | لا تُعطّله في النسخة المحلية |

## 7) متطلبات النظام

| الأداة | لماذا | التثبيت |
| :--- | :--- | :--- |
| **Python 3.10+** | تشغيل الخادم | python.org |
| **ffmpeg + ffprobe** | كل صيغ الصوت/الفيديو | `winget install ffmpeg` · `apt install ffmpeg` · `brew install ffmpeg` |
| **Tesseract + عربي** | OCR للصور و PDF الممسوح | `apt install tesseract-ocr tesseract-ocr-ara` |
| Node.js 18+ (اختياري) | بناء الواجهة (يُبنى مرة واحدة) | nodejs.org |

بدون ffmpeg يعمل النظام للمستندات فقط، ويظهر ذلك صراحةً في `/health`.
