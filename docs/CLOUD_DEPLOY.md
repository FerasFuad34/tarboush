## ماذا تفعل أول ما تفتح الرابط؟

1. اضغط زر **«جرّب محاضرة تجريبية»** — يُنشئ محاضرة ويعالجها فعلياً (ليس عرضاً ثابتاً).
2. بعد ~30 ثانية تفتح صفحة المحاضرة على تبويب **«الشرح والمصادر»**:
   - 3 مواضيع مستخرجة من نص المحاضرة.
   - 12 مصدراً حقيقياً (يوتيوب + ويكيبيديا) مع مصغّرات ومدة وقناة.
   - مقتطف حرفي من المحاضرة لكل موضوع.
3. من **«رافع محاضرة جديدة»** ارفع PDF / PPTX / DOCX / TXT / MD.

## تفاصيل تقنية عن النشر

| البند | القيمة |
| :--- | :--- |
| المستودع | `FerasFuad34/tarboush` (عام) |
| خدمة الـ API | `tarboush-api` — Python 3.12.6 — Free — Frankfurt — `rootDir=backend` |
| أمر البناء | `pip install -r requirements-render.txt` |
| خدمة الواجهة | `tarboush-web` — Static Site — أمر البناء `cd frontend && npm install && npm run build` — مجلد النشر `frontend/dist` |
| ربط الواجهة بالـ API | `VITE_API_URL=https://tarboush-api.onrender.com` (يُحقن وقت البناء) |
| النشر التلقائي | ✅ مفعّل للخدمتين — أي `git push` على `main` يُعيد النشر |

### دروس من النشر (أخطاء وقعت فعلاً وأُصلحت)

| المشكلة | السبب | الإصلاح |
| :--- | :--- | :--- |
| `build_failed` فوراً | Render اختار Python 3.14 (غير مستقر) ولم يجد `PYTHON_VERSION` | ضبط `PYTHON_VERSION=3.12.6` عبر API (`PUT /services/{id}/env-vars`) |
| حزم تُبنى من المصدر وتفشل | `pydantic-core` يتطلب Rust على 3.14 | نفس الإصلاح أعلاه |
| الواجهة تُرجع صفحة فارغة (0 بايت) | النطاق نُشر كـ `static_site` وفي الكاش `index.html` من نشر سابق بمسار خاطئ | إعادة إنشاء الخدمة بمجلد نشر صحيح `frontend/dist` + نشر بـ `clearCache` |
| `invalid runtime: static` | Render يقبل `static_site` لا `static`، ولا يقبل `region` لها | تصحيح نوع الخدمة في طلب الـ API |
| بحث يوتيوب يعيد صفراً أحياناً (403) | يوتيوب يحجب عناوين مراكز البيانات | إعادة محاولة تلقائية بعملاء `web → android → tv` + كاش للنجاح فقط |
